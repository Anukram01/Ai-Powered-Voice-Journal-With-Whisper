AI Powered Voice Journal is a web-based application developed using Python Flask, HTML, CSS, and JavaScript. The project allows users to record, save, and manage voice journal entries through a simple and interactive user interface. JavaScript is used to handle voice recording and frontend interactions, while Flask manages backend processing, routing, and data handling. The application also includes features like user authentication, dashboard, and journal history management, making it a smart and organized digital journaling platform.

This project is designed to provide users with a modern way of maintaining personal journals using voice technology. The frontend is built using responsive web technologies to ensure smooth user experience, while the backend efficiently processes and stores user data. The project demonstrates the integration of AI concepts, voice processing, and full-stack web development in a practical real-world application.
